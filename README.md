# The Wild Slasher (눈을 떠요 야생소년 감성의 실시간 핵앤슬래시 RPG)

《눈을 떠요 야생소년 (The Wild Darkness)》의 아기자기하면서도 다크한 쿼터뷰 2D 도트 감성과, 《디아블로 3 / 토치라이트》의 손맛 있는 100% 실시간 조작 기반 핵앤슬래시 액션 파밍 시스템이 결합된 모바일(가로모드) & PC 하이브리드 액션 RPG 프로토타입입니다.

---

## 🎮 핵심 게임 시스템 및 메커니즘

### 1. 스탯 포인트 및 자유 성장 (Attributes)
* **레벨업마다 스탯 포인트 (+5 pt)**가 부여되며 자유롭게 분배할 수 있습니다.
* **힘 (STR)**: 물리 공격력 대폭 증가, 장비 요구치
* **민첩 (DEX)**: 이동속도 증가, 치명타 확률 증가, 원거리/보조 공격력
* **지능 (INT)**: 최대 마나 증가, 스킬 쿨다운 감소 (최대 40%)
* **체력 (VIT)**: 최대 생명력 대폭 증가, 물리/속성 방어력 증가
* **행운 (LUK)**: 치명타 피해량 증가, **디아블로식 고등급 아이템(마법/희귀/전설) 드롭률(Magic Find) 증가**

### 2. 레벨링 & 환생(Prestige) 시스템
* **최대 레벨은 100**으로 고정됩니다.
* 월드 난이도는 1부터 100까지 존재하지만, **1회차(환생 0회)에서는 100레벨을 달성하더라도 난이도 20 수준에서 스펙 벽**에 부딪힙니다.
* **환생(Rebirth)**을 실행하면:
  * 캐릭터 레벨은 1로 리셋됩니다.
  * **환생 1회당 5레벨 분량(+25 pt)의 스탯 포인트를 영구 귀속 보너스**로 영구 소지하고 시작합니다. (2회차 100렙은 105렙 상당, 3회차는 110렙 상당)
  * 환생 시 직업(전사/궁수/마법사/도적)을 다시 선택할 수 있습니다.

### 3. 절차적 맵 생성 (Procedural Content Generation)
* 매 회차 및 진입 시 **Cellular Automata 알고리즘**을 통해 장애물, 벽, 통로, 보물상자, 몬스터 스폰 위치, 차원 관문(빛의 유적)이 매번 무작위로 생성됩니다.

### 4. 다이내믹 바이옴 셔플 & 난이도 티어링
* 월드는 **5대 바이옴**(초원, 사막, 열대 늪지, 극지 설원, 화산)으로 구성됩니다.
* 환생할 때마다 5개 바이옴의 난이도 티어(20, 40, 60, 80, 100)가 **무작위로 셔플**됩니다.
* **플레이어는 항상 이번 회차에서 난이도 20으로 배정된 바이옴에서 태어나므로**, 매 환생마다 완전히 새로운 환경과 몬스터를 초반부터 상대하게 됩니다.

### 5. 5대 바이옴 생태계 및 환경 기믹
* **고요한 초원 (Grassland)**: 늑대, 고블린, 숲 곰 / 울창한 숲
* **작열의 사막 (Desert)**: 전갈, 미라, 사막 벌레 / 모래폭풍 열사병 기믹
* **독성 정글 (Tropical Swamp)**: 독거미, 독개구리, 원시 주술사 / 독 웅덩이 장판
* **혹한의 설원 (Tundra)**: 서리 늑대, 설인(예티), 얼음 골렘 / 이동·공격 둔화 한기
* **파멸의 화산 (Volcanic)**: 화염 임프, 마그마 슬라임, 헬하운드 / 분출하는 용암 장판

### 6. 디아블로식 장비 파밍 (Diablo-style Loot)
* 등급: **일반(Normal - 흰색)**, **마법(Magic - 파란색)**, **희귀(Rare - 노란색)**, **전설(Legendary - 주황색)**
* 슬롯: 무기, 갑옷, 투구, 신발, 목걸이, 반지 (총 6부위)
* 수백 가지 조합의 접두사/접미사 옵션 부여 ('학살자의', '용사의', '광폭의', '철벽의' 등)
* 몬스터 처치 시 디아블로 특유의 **빛기둥 빔(Loot Pillar)** 연출 및 자석형 자동 습득

### 7. 가로모드 모바일 & PC 하이브리드 컨트롤
* **모바일**: 좌측 화면 드래그로 **가상 아날로그 조이스틱(Virtual Joystick)** 이동 + 우측 디아블로식 **원형 스킬 휠 버튼** (베기, 휠윈드, 돌진, 지면강타, 전투함성)
* **PC 키보드/마우스**:
  * 이동: `W`, `A`, `S`, `D` 또는 방향키
  * 기본 공격 (베기): `Space` 또는 마우스 좌클릭
  * 스킬 1 (휠윈드): `1`
  * 스킬 2 (돌진/회피): `2` 또는 `Left Shift`
  * 스킬 3 (지면강타): `3` 또는 `E`
  * 스킬 4 (전투함성): `4` 또는 `Q`
  * 단축키: `C` (스탯), `I` (가방), `R` (환생), `B` (자율 QA 봇 토글)

### 8. 자율 플레이테스트 봇 (Autonomous QA Bot)
* 상단 우측의 **[🤖 QA봇]** 버튼(또는 키보드 `B`)을 누르면, 기사에서 다룬 것처럼 **에이전트 봇이 게임을 자율적으로 플레이**합니다.
* 몬스터를 스스로 탐색하여 접근하고, 쿨다운에 맞춰 스킬 콤보를 시전하며, 드롭된 장비를 줍고, 스탯을 자동으로 분배하며 던전을 돌파합니다.

## 📱 안드로이드 APK 패키징 가이드 (Capacitor)

현재 프로젝트는 순수 웹 표준(HTML5 Canvas/JS) 기반으로 설계되어 있으므로 Capacitor를 통해 바로 APK로 빌드할 수 있습니다:

```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "WildSlasher" "com.wild.slasher" --web-dir "."
npx cap add android
npx cap open android
```
안드로이드 스튜디오에서 `Build > Build APK`를 선택하면 스마트폰에 설치 가능한 가로모드 APK가 생성됩니다.
